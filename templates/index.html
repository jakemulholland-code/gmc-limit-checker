See what Google cuts off

Google truncates fetched HTML at 2,097,152 bytes. This tool measures where that cut lands and shows which page sections are kept, partially clipped, or lost entirely — with an optional analysis of what could be trimmed.

Google's View — rendered up to the cut

A visual approximation of the page as Googlebot fetches it — only the HTML up to 2MB is rendered, so anything below the cut is missing. External CSS & images load from the live site, so it won't be pixel-perfect and scripts are disabled for safety.
